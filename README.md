# Rock Paper Scissors Game

A browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features

- 🎮 Play Rock Paper Scissors against the computer
- 🤖 Computer generates a random choice
- 📊 Live user and computer score tracking
- 🌓 Dark Mode / Light Mode toggle
- 🎯 Instant result after every round
- 🎨 Interactive choice hover effects
- 📱 Simple and responsive interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/PiyushThakur1107/rock-paper-scissors.git
```

2. Navigate into the project:

```bash
cd rock-paper-scissors
```

3. Open `index.html` in your browser.

## How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer randomly selects its choice.
3. The winner is determined by the standard rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
4. The score is updated after each round.
5. Use the **Dark Mode / Light Mode** toggle to change the appearance.
